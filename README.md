# Python Fundamentals & Core Concepts

This repository contains my daily practice files and hands-on exercises as I master Python programming to transition into software engineering.

## 🚀 Topics Covered
* **Basic Outputs:** Understanding `print()` with different data types (Integers, Floats, Strings).
* **Code Documentation:** Implementing single-line (`#`) and multi-line (`'''`) comments.
* **Text Formatting:** Working with Escape Sequences like `\n` (newline), `\t` (tab), and escaping quotes (`\"`, `\'`).

## 📁 File Structure
* `program1.py` - Introduction to standard outputs and data types.
* `program2.py` - Practical implementation of string formatting and documentation.

## 🛠️ Environment
* **IDE:** Thonny
* **Language:** Python 3
